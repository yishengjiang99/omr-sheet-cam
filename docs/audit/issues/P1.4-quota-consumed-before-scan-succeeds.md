**Static verdict from audit:** GAP (confirmed by code trace)
**Build / env:** traced at HEAD `736d0f6` (main) · iOS 17+ · static code trace, not yet reproduced on device/Simulator · StoreKit env: Xcode config (needs attach, see P11.3) / Sandbox · Apple ID type: sandbox tester

### Expected
A scan that fails because of the app (reader unavailable/warmup failure) or that the user cancels does not consume daily quota; only successful recognitions (or at least not app-caused failures) count. "Try again" must keep not charging.

### Actual
`RootFlowView.handlePhoto` calls `quota.checkAndConsume()`, which increments `omr.freeScansUsed` immediately (`set(used + 1)`), then pushes `.result(photo)`. Recognition, success/failure and Cancel all happen later in `ResultScreen`, which has no link back to the quota. Failed scans (blank page, models not ready), cancelled scans and the bundled sample picture each cost 1 of 5.

### Location
- `Sources/App/RootFlowView.swift:57-63` (consume then push result)
- `Sources/App/Services/ScanQuota.swift:22-38` (increment at :36)
- `Sources/App/Capture/ResultScreen.swift:245-271` (outcome known here; no quota refund)
- `Sources/App/Capture/ResultScreen.swift:58` (Cancel = dismiss only)
Root cause (1-2 lines): Quota is a pre-flight gate that increments, not a reservation that is committed on success.

### Repro
1. `defaults write com.ragnus.vp omr.freeScansUsed -int 0` (or fresh install).
2. Force a failure: scan a blank white image (or remove models in a debug bundle -> readerUnavailable), or tap Cancel on the Reading screen.
3. Observed: `omr.freeScansUsed` == 1 after each; 5 failed/cancelled scans -> paywall on the 6th.

Repro rate: always
Evidence: static trace at HEAD with file:line above (no screenshot/recording yet)

### Severity
P1 — revenue/trust-affecting - users are pushed to the paywall by app-side failures and cancels.

### Suggested fix
Split into `canScan()` (check only, shows paywall) + `commit()`/`refund()`; call `commit()` from `ResultScreen.recognize` on `.recognized` (via closure or shared `ScanQuota.shared`). Alternative: keep pre-charge but refund on `.failed(readerUnavailable)`/cancel. Product decision: should sample picture count?
