**Flow:** P6 Restore purchases
**Static verdict from audit:** GAP (confirmed by code trace)
**Build / env:** traced at HEAD `736d0f6` (main) · iOS 17+ · static code trace, not yet reproduced on device/Simulator · StoreKit env: Xcode config (needs attach, see P11.3) / Sandbox · Apple ID type: sandbox tester

### Expected
"Restore purchases" is reachable from the paywall AND from Settings, with no quota hit needed (App Review 3.1.1 expects an obvious Restore).

### Actual
`restore()` is called from exactly one place: the "Restore purchases" button inside `PaywallView`. The paywall is only ever presented by `ScanQuota.checkAndConsume()` after the 5th free scan of the day (`showPaywall = true`). `SettingsView` sections are only Playback / About / Developer; there is no Pro/Restore/Manage-subscription row. A paying user on a new device/reinstall whose entitlement did not sync must burn 5 scans first to see Restore. (`ScanQuota.shared.showPaywall` is the only presenter.)

### Location
- `Sources/App/Features/Paywall/PaywallView.swift:43-47` (only Restore button)
- `Sources/App/Services/ScanQuota.swift:31-34` (only code that sets showPaywall)
- `Sources/App/Settings/SettingsView.swift:57-67,95-138` (no Pro/Restore row)
- `Sources/App/RootFlowView.swift:50-52` (paywall sheet bound to quota.showPaywall)
Root cause (1-2 lines): Paywall is the only IAP UI surface and it is quota-gated; Settings has no subscription section.

### Repro
1. Fresh install (or reinstall) with an active subscription on the Apple ID where auto-sync has not populated entitlements.
2. Open Settings: no Restore/Pro row. Library/Camera: no Pro entry.
3. Observed: Restore can only be found after using 5 scans and hitting the paywall.

Repro rate: always
Evidence: static trace at HEAD with file:line above (no screenshot/recording yet)

### Severity
P1 — restore unreachable for most users; App Review risk; support burden.

### Suggested fix
Add a Settings section "Music Reader Pro" with: plan status, "Restore purchases" button (calls `storeKit.restore()` with feedback - see the restore-feedback issue), "Manage subscription" (`.manageSubscriptionsSheet`), and a way to open the paywall voluntarily (also fixes P1.13). Share the single `StoreKitManager` environment object.
