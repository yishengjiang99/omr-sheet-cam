### Expected
Free users see how many scans are left; free users can discover/upgrade without hitting the wall; after purchase the user gets visible confirmation and Settings shows plan/renewal with Manage subscription.

### Actual
`ScanQuota.scansRemaining` is defined but never read by any view (`rg scansRemaining` hits only its definition). The paywall is presented only by the quota gate. On purchase success the sheet silently dismisses (`if ok { dismiss() }`); no toast, no Pro badge; Settings has no Pro/plan row; there is no `manageSubscriptionsSheet`. Plan changes (monthly<->yearly) are unreachable in-app for Pro users.

### Location
- `Sources/App/Services/ScanQuota.swift:40-45` (scansRemaining unused)
- `Sources/App/Features/Paywall/PaywallView.swift:83-84` (silent dismiss)
- `Sources/App/Settings/SettingsView.swift:57-67` (no Pro section)
- `Sources/App/Services/ScanQuota.swift:33` (only presenter of the paywall)
Root cause (1-2 lines): Monetization UI was built paywall-first; no status surfaces.

### Repro
1. Scan 3 times: nowhere shows "2 left".
2. Subscribe: sheet closes, nothing says Pro is active; Settings has no plan info.

Repro rate: always
Evidence: static trace at HEAD with file:line above (no screenshot/recording yet)

### Severity
P2 — conversion/UX gap with workarounds.

### Suggested fix
Show "N scans left today" (Library/Camera) from `scansRemaining` (make `ScanQuota` publish the count); add Pro section in Settings (status, renewal date from `Transaction`, Manage subscription, Upgrade/Restore); toast "You're Pro" on purchase success.
